# Online Makeup Store Database

This project is a MySQL database system for an online makeup store.

## Features

* Manage customers
* Manage products
* Store orders
* Track order details

## Database Tables

* CUSTOMER
* PRODUCT
* Orders
* ORDER_DETAILS

## Concepts Used

* Primary Key
* Foreign Key
* JOIN
* Subquery
* View
* Aggregate Functions

## Tools Used

* MySQL
* MySQL Workbench
